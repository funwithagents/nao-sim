# `NaoSim` and `nao-sim run`

**Status:** Done

Implements [config.md](../specs/runtime/config.md), the rest of [api.md](../specs/runtime/api.md) (the `NaoSim` object, `read_status`, `cleanup`), [cli.md](../specs/runtime/cli.md) (`run`, `cleanup`, `status`, `logs`) and the window part of [viewer.md](../specs/host/viewer.md). The live tier moves onto `NaoSim` with a `MemorySink`. The audio output becomes internal to `NaoSim`: its command, the `nao-sim-speaker` script and the stdout events are removed, and the specs say so. Left out: the host devices that are not built (audio, video and touch inputs: the config accepts them and `start()` refuses them), the render camera, the distribution (package data, user data directory) and CI.

## Steps

1. **`config.py`**, as config.md says, on the pattern nao-bridge and nao-viewer share:
   - frozen dataclasses, one per block, each with `parse(data, path)` checking the type of every key, rejecting unknown keys and letting the dataclass default the missing ones, and `__post_init__` checking ranges and `Literal` values with `ConfigError(message, key=field)`;
   - `ConfigError(ValueError)` carries `key`; each enclosing parser prefixes it with the block's path, and `str()` reads `key: message`;
   - cross-field checks in `NaoSimConfig.__post_init__` (`record` needs `audio_output.record`, `wav` needs `audio_input.wav`);
   - `from_dict`, `from_json`, `from_json_file` on every class; the file loader resolves `audio_output.record`, `audio_input.wav` and a `.xml` `viewer.scene` against the file's directory.
2. **`stack.py`**:
   - `up(config)`: `docker compose --profile <v> up -d --no-build tts <service>` with `NAO_SIM_TTS_ENGINE` in the environment; `down(version)`: `docker compose --profile <v> down`;
   - `wait_ready(version, timeout)` is `docker_images.wait_healthy`;
   - `read_status()` (async): `docker compose -p nao-sim ps -a --format json` for the containers; when the NAOqi one is healthy, a qi session with the connect retry reads `getVersion`, `getNaoqiVersion`, `isReady` and the two `NaoSim/*/Source` keys into a `NaoSimStatus`;
   - `cleanup()` (async): refuses with `NaoSimError` when 9562 is taken, else `docker compose --profile '*' down` and returns the names `ps` listed before;
   - `show_logs(follow, tail) -> int`: `docker compose -p nao-sim logs`, output to the terminal.
3. **`viewer.py`**: `needs_viewer(config)` per the table of viewer.md; `viewer_config(settings, url)` imports `nao_viewer` (`MissingExtraError` naming `nao-sim[viewer]` when absent) and re-raises its `ConfigError` as ours with key `viewer.<field>`; `SimWorld(viewer_config)` with `launch()`, `close()`, and a daemon thread on `NaoViewer.wait()` that logs the window closed once (not when `close()` caused it).
4. **`sim.py`**: `NaoSim` as api.md: construction (config, version string, `sink=`), the loaders, `config`, `running`, `url`, `status()`, `start()`/`stop()`/`async with`.
   - `start()` step 1 in one thread: Docker, `check_images`, the viewer (extra, config), `DeviceNotBuiltError` for any `audio_input` or `video_input` source but `none`, ports 9559 and 9562 free;
   - then the audio output (`Server(("0.0.0.0", 9562), AudioOutput(sink))` on a thread), compose up, the wait, the viewer; a list of undo actions grows with each step, and any failure (cancellation included) runs it in reverse before re-raising;
   - `stop()` runs every undo action, keeps going on errors and raises the first; the sink built from `record` is a `WavSink` closed there.
5. **`cli.py`**: `run` builds a `NaoSim` from `--config` (or the defaults), starts it with SIGINT/SIGTERM handlers that cancel the start or end the wait, prints the URL and the versions, waits, stops; `status` prints `read_status()` and exits 0 only when ready; `cleanup` prints what it removed; `logs` passes `--follow`/`--tail`. `ConfigError` exits 2, `NaoSimError` 1, a Ctrl-C during the start 130.
6. **Audio output**: remove `main()`, `print_event`, the argparse import and the `__main__` block; the `AudioOutput` events go to the debug log only.
7. **Live tier**: the `nao` fixture keeps the image check-and-build step, then starts `NaoSim(NaoSimConfig(naoqi.version, viewer.headless=true, audio_output.mode=silent), sink=MemorySink())` through an `asyncio.Runner`; `Nao` gains `sink`, `restart()` and `stop()`/`start()`; `Container` keeps the `docker exec/cp/inspect` helpers (`tts_log`, `copy_in`, `image_env`, `health`). Speech tests read durations from the `MemorySink`. New tests: `status()` and `read_status()` on the running sim, `cleanup()` refusing while it runs, `nao-sim run` with `headless.json` in a subprocess (ready line, `nao-sim status` exits 0, SIGINT exits 0 and leaves no container), the window (skips without a display or the extra).
8. **Specs and docs** as listed in Scope; spec statuses: config.md, cli.md and viewer.md `Implemented`, api.md `Implemented` except the distribution's "Files on disk" wheel column (owned by project.md, still `Updated`).
