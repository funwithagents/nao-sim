# Audio sinks and the audio output rename

**Status:** Done

Implements [audio-output.md](../specs/host/audio-output.md) ("Naming", "Command", "Audio sinks", "Playing state"): the speaker becomes the audio output (`src/nao_sim/audio_output.py`, class `AudioOutput`), where its audio goes becomes an `AudioSink` (`DevicePlayer`, `NullSink`, `WavSink`, `MemorySink`), and it keeps `playing_until` current. The protocol and its semantics do not change. Left out: the `NaoSim` object that will own the audio output, and moving the live tier onto a `MemorySink` (both in the `NaoSim` plan); the `nao-sim-speaker` script stays until then ([cli.md](../specs/runtime/cli.md), "Existing commands"), pointing at the new module.

## Steps

1. **Rename** with `git mv` (module and test), then update every reference listed above.
2. **Sinks.**
   - `AudioSink` is a `typing.Protocol` with `begin(rate, channels)`, `feed(chunk)`, `end(interrupted)`.
   - `NullSink`: does nothing.
   - `WavSink(path)`: mono 16-bit WAV; reopens (overwrites) the file when the rate changes; downmixes interleaved multi-channel PCM to mono with numpy (mean of the channels); `close()` finishes the file. `wave` patches the header at every write, so the file is readable between streams.
   - `DevicePlayer(device=None)`: imports `sounddevice` at the first `begin`, opens a `RawOutputStream(samplerate, channels, dtype="int16", device=device)` per stream, `write`s each chunk; `end(interrupted=False)` calls `stop()` (drains), `end(interrupted=True)` calls `abort()` (cuts at once), then `close()`.
   - `MemorySink`: a `Playback(rate, channels, pcm: bytes, started_at, ended_at: float | None, interrupted)` dataclass per stream (times in `time.monotonic()`); `playbacks` returns a copy of the list; `wait_for(predicate, timeout=5.0) -> Playback` returns the first *ended* playback the predicate accepts, waiting on a `threading.Condition`, `TimeoutError` otherwise.
3. **`AudioOutput(sink, on_event=None)`.**
   - **Pacing in the audio output, for every sink**: chunks of 100 ms; after feeding a chunk, `playing_until = t0 + fed_s`, then sleep until `playing_until - 0.1`, so a device keeps one chunk queued and never underruns. When the data ends, sleep until `playing_until`, so `play` returns as the audio finishes, as today.
   - **Newest wins, with the call discipline**: a new stream takes a generation number and sets the stop flag, then waits on a sink lock held by the current stream from `begin` to `end`; the old stream sees its generation is stale at its next chunk, ends with `interrupted=True` and releases the lock. `end` is called in a `finally`, so it runs exactly once even when the sink or the socket fails.
   - **Playing state**: `playing_until` is set at every chunk and set to `time.monotonic()` on a stop or an interruption; `0.0` until the first stream.
   - **Events**: `on_event(dict)` receives `start` (`rate`, `channels`), `interrupted` and `end` (`played_s`), `stop-request`. With none, they go to `logging.getLogger(__name__)` at debug level. `main()` passes a printer that adds `t` and writes one JSON line to stdout, as today, and prints `listening` itself.
4. **`main()`**: `--record FILE` → `WavSink`, `--silent` → `NullSink`, otherwise `DevicePlayer()`; both `--record` and `--silent` → `WavSink` (recording never opens a device, as today's `--silent --record`). Closes a `WavSink` on exit. `if __name__ == "__main__"` so `python -m nao_sim.audio_output` runs it.
5. **Tests** (`tests/test_audio_output.py`), on an in-process server on a free port:
   - keep today's four: real-time pacing with every sample recorded, stop within one chunk, newest wins, bad header ignored — asserting on a `MemorySink`'s playbacks (`interrupted`, `len(pcm)`) instead of stdout;
   - **call discipline**: a recording sink's call log under newest-wins shows `begin`/`feed*`/`end` per stream, never overlapping, `end(True)` for the cut stream;
   - **playing state**: `playing_until` is in the future during a stream, about its end time when the stream ends, and jumps to now on a stop;
   - **`WavSink`**: two streams at one rate append to one file; a stream at another rate overwrites it with the new rate; stereo is downmixed to mono;
   - **`DevicePlayer`**: with a fake `sounddevice` module in `sys.modules`, nothing is imported before `begin`, the stream receives the chunks, and an interruption aborts instead of draining;
   - **command**: `main(["--listen", "127.0.0.1:0", ...])` is not run (it serves forever); the stdout format is covered by `on_event` via a test of the printer.
6. **Live tier**: `AudioOutputProcess` (renamed from `SpeakerProcess`) runs `-m nao_sim.audio_output`; the session fixture becomes `audio_output`; the speech tests take it under that name. Events are unchanged.
